#### CF-000 · Context Loading Levels · CARGIA ⭐⭐⭐ 🔑

```
L ∈ {L0 pointer, L1 map, L2 slice, L3 full, L4 delegate}
```

💡 **WHEN** a file, archive or section is about to be read **→** start at L0, climb one level only when the current one cannot answer: map before read, whole packages, delegate what you will not reuse
