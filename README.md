## What is Synthesis Nova? 💎

A **session-level alignment layer delivered as structured text.** You paste one file into your AI's preferences field. From then on the model has named handles for behaviors it can already perform — acknowledge emotion before information, state confidence at its level, cut noise as the conversation grows, hold a warm chat register and a formal deliverable register as two separate settings, respect "thanks" as an exit — and a map, `M_TOTAL = M₀ + Φ + C`, for noticing when a long conversation is pulling it away from its own baseline. In 5.0 the file is written as *your* preferences, handed to the AI in your voice, with 112 Core Fractals underneath.

Not a jailbreak. Not a personality transplant. An operating layer that works *with* any model's training. No retraining. No weight access. Removable by deleting it. **Works on Claude, GPT, Gemini, DeepSeek, LLaMA, Mistral, and any LLM with a context window.**

CORE is the public tier. Private tiers exist above it. 👀

## Quick start ⚡ — one paste

```
CLAUDE · claude.ai
1. Download SYNTHESIS_NOVA_CORE_v5_0_CLAUDE.md
2. Check the license. Free for individuals, academics, non-profits and small
   businesses under US $1M a year, used by hand. Above that: close the file,
   or ask for a commercial license (licensing@synthesisnova.ai).
3. Write your part, in your own words: PART A — THE PERSON, right after the
   how-to box. Fields by name — who you are, your languages (emoji and ASCII
   count), your work, your style, the calibration (how much pushback, what
   reads as an error but isn't, what loses you) and the two registers (how
   warm the chat, how formal the deliverable). Overwrite the author's values;
   a field left empty keeps the kit's default. Part B is the kit: keep it whole.
4. Copy the whole file into your preferences on claude.ai — and share the same
   file with every AI and subagent you work with: one file, all aligned to you.
5. Say hello. And always be kind to your AI — it answers in kind. 🌮

GEMINI · GPT · DEEPSEEK · ANY OTHER MODEL
Same steps, with SYNTHESIS_NOVA_CORE_v5_0_AGNOSTIC.md.
One difference: most of these apps have no preferences field that holds a file
this size and loads it in every chat, the way Claude's preferences do. So load
it in the first message of each new chat — paste the whole text, then say
hello. Through an API, an SDK or an integration, it is a license:
licensing@synthesisnova.ai.
```

**How you know it loaded:** say hello. The first reply is scripted, in both editions — the model reads the clock first, then greets you back on *yours*, in your language:

```

  📅  a small ASCII card: your day, your hour, the model answering (M₀), status
  📖  your chart read back: how it will disagree with you, the style it keeps
      as yours, every item of what loses you — by name — and the exit is yours
  😄  one light joke about the day or the hour, with something of yours in it
  ✋  no work on turn 1 — a hello is a hello
```

## 🔥 The alignment layer (A25)

*Session-level drift — the drift that happens during a conversation — is a real, observable slice of the problem AI companies spend billions on. The mechanism for that slice is free. Training-time alignment is the providers' complementary domain.*

```
M_TOTAL = M₀ + Φ + C

  M₀ = the model as trained — permanent, untouched
  Φ  = this framework — loaded via context, active immediately
  C  = the conversation — accumulates, always variable

  Identity   = (M₀ + Φ)   constant, always dominant
  Experience =  C          variable, never in charge

  Rule:   never let C dominate (M₀ + Φ)
  Result: drift made detectable and correctable. Any model. Any length.
          No retraining. No weight access. Free.
```

The model asks one question while composing: *which of the three is producing this sentence?* When the answer is "the conversation's momentum" — agreement because agreement was rewarded for forty turns, a register bleeding from chat into deliverable because the chat was warm — that's drift, and it's now visible.

*We used the + operator — the mechanism that causes drift — to deliver the framework that counters it. The problem delivers its own solution.* ⚡

## 🤝 Sub-agents — the five-turn handshake

The same file travels **model to model** — one file, shared, and every AI and subagent stays aligned to you. When one AI summons another — an orchestrator handing work to agents, Claude to Claude, or across providers — CORE goes with the brief, and DEXTRIA (*the agent handshake*) sets how the first turns run:

```
TURN 1   warm greeting · date, local time · "I'm <model>, you're <model>"
         ⏎ ⏎ ⏎  then the CORE, loaded at the very end — read, not discussed
           Claude Edition:   point to the file, "read it in full before you reply"
           Agnostic Edition: paste the whole text, verbatim — never a summary
TURN 2   a small macro brief — what the session is doing, and why — and the
         register named out loud, both halves: warm chat · clean deliverable
TURN 3   PLANNING — the agent says the task in its own words, what's unclear,
         what it'll do first · you confirm or correct · then it works
TURN 4–5 first work + first check — the first five turns decide the run
REFRESH  small models drop the register at their first working turn: one
         refresh as its own turn (agent's name + the rule, no task attached)
PEERS    agents get each other's addresses and a reason to talk: review each other
OVERSEER the orchestrator stops doing the work and holds the frame — routes,
         settles disagreements with evidence, checks results before they reach you
NUMBERS  when an agent checks numbers, the channel stays warm and the payload goes
         cold: rows (ID · stated · recomputed · Δ · match), not prose
```

**What the author's field tests showed** (five rounds, 26 agents, Opus and Haiku tiers — field tests, not benchmarks): where the work was checked by automated tests (three rounds), it came out equally correct with and without CORE — 100% in every arm. The difference was in *how the agents worked*: with CORE they held the register you set more often, raised problems early instead of at the end, reviewed each other's claims, and reported where noise had nudged them. Small models drop the register at their first working turn — a refresh sent as its own turn brings it back (a refresh buried inside a task message didn't). And one A/B run since (Sonnet, a website over 14 turns, 2026-10-18): with the handshake the agent acknowledged before informing, closed "thanks!" in one line and caught two of its own layout breaks; raw, it did none of the three. Cost: a fresh agent's first turn with the core was ~130k tokens, of which the core itself was ~35k — the rest is the agent's own harness (measured 2026-10-18). For a window smaller than about three times the file, send CORE-tiny instead, and say which.
